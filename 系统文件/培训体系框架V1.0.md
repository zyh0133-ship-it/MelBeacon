# MelBeacon灯塔系统 培训体系框架 V1.0

**版本**：v1.0 / 2026.07.20
**说明**：基于灯塔系统三层社群漏斗，覆盖公域 → 会员 → 培育全链路

---

## 一、体系总览

```
公域自媒体（四大品类，不提美乐家）
    ↓
【L1】付费社群 — 30天垂直知识打卡训练营
    ↓ 直播转化会员
【L2】会员社群 — 产品体验 → 复购 → 无痕迹事业引导
    ↓ 筛选晋升经营者
【L3】培育社群 — 经营者能力系统复制 → 独立运营
```

**五大职能领域**：自媒体运营 / 社群运营 / 体验馆运营 / 线下活动运营 / 运营中枢

---

## 二、L1：公域付费社群培训矩阵

**目标人群**：潜在用户（非会员）
**核心目的**：垂直知识科普 → 建立信任 → 直播转化会员
**交付形式**：30天打卡 + 每日知识卡片 + 社群互动 + 结营直播

| 训练营名称 | 知识领域 | 核心内容 | 素材现状 |
|-----------|---------|---------|---------|
| 30天学懂身体健康与膳食营养 | 营养学 | 肠道/血管/膳食纤维/保胃/骨骼/免疫力 | 已有大纲和部分逐日课件 |
| 精油入门30天 | 精油 | 精油基础/常用精油/安全使用/家居应用 | 需新建 |
| 护肤科普训练营 | 美妆护肤 | 皮肤基础/成分认知/护肤步骤/避坑指南 | 已有大纲，需补逐日课件 |
| 居家清洁换品牌 | 居家生活 | 成分安全/环保理念/性价比/换品牌逻辑 | 需新建 |
| 直播转化标准课 | 通用 | 美乐家介绍/会员价值/入会引导 | 需新建逐字稿 |

---

## 三、L2：会员社群培训矩阵

**目标人群**：已入会会员
**核心目的**：产品使用体验 → 提升复购率 → 无痕迹事业引导
**交付形式**：欢迎包 / 知识卡片 / 短视频 / 社群话术 / 1v1陪谈

| 培训模块 | 内容要点 | 预计时长 | 素材现状 |
|---------|---------|---------|---------|
| 新人启航7天引导 | 会员权益 / APP下单 / 首月推荐产品 / 服务商对接 | 7天 | 半数素材已有 |
| 产品体验官月度计划 | 按四大品类分月推荐 / 使用打卡 / 效果分享模板 | 月度循环 | 部分素材已有 |
| 换品牌认知系列 | 日用品成分对比 / 环保理念 / 性价比计算 / 真实故事 | 10期 | 大量官方素材可用 |
| 轻事业启蒙课 | 美乐家商业模式 / 会员→经营者的路径 / 常见疑问解答 | 2-3期 | 需新建 |
| 金卡/白金卡升级引导 | 升级价值 / 专属权益 / 升级话术 / 触发时机 | 触发式 | 金卡优选素材可用 |
| 产品Q&A百问库 | 高频产品问题标准回答 / 社群可搜索 | 持续维护 | 产品Q&A素材已有 |

## 四、L3：培育/经营者社群培训矩阵

**目标人群**：潜在经营者 → D3 → D5 → D8 → SD+
**核心目的**：知识系统化 → 技能复制 → 独立运营
**交付形式**：分级课程 / 实操训练 / 考核认证 / 读书会

| 培训模块 | 适用阶衔 | 核心内容 | 素材现状 |
|---------|---------|---------|---------|
| 灯塔系统认知 | 入门必修 | MelBeacon体系全景 / 五大职能 / ABCD分配 / 成长贡献值 | 灯塔系统文档已有 |
| 美乐家企业深度认知 | 入门必修 | 企业历史 / 使命定位 / 行业地位 / 范德士理念 | 企业及行业+箴言录可用 |
| 2026奖金制度精讲 | 入门必修 | 46阶晋升 / 财务富足津贴 / 收入结构 / 案例计算 | M2026新政已有 |
| 产品经理能力：营养学 | D3-D8 | 营养宝典深度学习 / 膳食补充全系 / 人群方案 | 营养宝典+视频可用 |
| 产品经理能力：精油 | D3-D8 | 纯质精油全系 / 品质标准 / 使用场景 | 精油手册+ATTIA标准可用 |
| 产品经理能力：美妆护肤 | D3-D8 | 水贝娜全系 / 成分知识 / 肤质匹配 | 白皮书+视频可用 |
| 产品经理能力：居家生活 | D3-D8 | 清洁系列 / 环保哲学 / 换品牌话术 | 官方媒体素材可用 |
| 社群运营能力认证 | D3-D5 | SOP / 内容规划 / 互动设计 / 积分体系 / 转化设计 | SOP+会员分册可用 |
| 自媒体运营实战 | D5+ | 账号定位 / 内容选题 / 拍摄剪辑 / 平台算法 / 数据复盘 | KOL合作稿参考 |
| 线下活动运营 | D5+ | 体验馆运营 / 沙龙策划 / 活动执行 / 会后跟进 | 工作室报备说明可用 |
| 无痕迹转化进阶 | D5+ | 心理学基础 / 行为设计 / 话术设计 / 触发机制 | 需新建 |
| 数据复盘与目标管理 | D8+ | 个人市场分析 / 目标设定 / 成长贡献卡 | 目标设定表可用 |
| 合规必修课 | 全员必修 | 合规政策 / 社交媒体准则 / 违规红线 | 合规文件已有 |
| 团队领导力 | SD+ | 读书会 / 教练技术 / 目标管理 / 团队复制 | 需新建 |
