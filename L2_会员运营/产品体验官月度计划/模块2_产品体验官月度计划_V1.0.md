# 产品体验官月度计划 V1.0

**版本**：v1.0 / 2026.07.20
**适用场景**：会员社群长期运营，每月一个品类深度体验
**目标人群**：已入会1个月以上的活跃会员
**交付形式**：月度主题包（产品清单 + 30天体验日历 + 每日社群话术 + 分享模板）
**合规声明**：功效描述根据美乐家官方描述；营养知识为科普性质，非产品功效宣称

---

## 总览：四品类月度轮换

| 月份 | 品类 | 主题口号 | 选购方式 |
|------|------|---------|---------|
| 第1月 | 营养辅助食品 | 「吃对营养，身体会说话」 | 会员自由选购 + 推荐基础营养包 |
| 第2月 | 精油与身体护理 | 「植物的力量，从一滴精油开始」 | 推荐精油入门套组 |
| 第3月 | 水贝娜美妆护肤 | 「给肌肤真正需要的」 | 根据肤质推荐匹配产品 |
| 第4月 | 居家清洁与个护 | 「换掉一瓶，改变一个家」 | 推荐入门清洁套组 |

> 四季轮换结束后，根据会员反馈调整顺序和内容
